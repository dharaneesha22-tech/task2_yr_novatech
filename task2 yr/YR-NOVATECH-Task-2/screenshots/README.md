# Screenshots — YR NOVATECH Task 2

This folder is reserved for screenshots of the running application.

Screenshots should be captured **after the application is running** and added here manually.
Do not add AI-generated or fabricated screenshots.

---

---

## How to Take Screenshots

**Windows:**
- Press `Windows + Shift + S` for a region screenshot.
- Or press `Print Screen` and paste in Paint.
- Save as `.png` in this folder.

**Browser:**
- Use the browser's full-page screenshot extension if needed.
